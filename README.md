# High-Precision-DeRainNet
A residual channel-attention CNN for single-frame rain removal, trained on Y-channel luminance with Charbonnier + structural loss. Includes ablation studies on attention, residual learning, depth/width, and loss design.
HighPrecisionDerainNet is a deep learning model built to remove rain streaks and rain-induced degradation from images, restoring a clean, visually accurate version of the scene. It's designed as a single-image (or single-frame) deraining network, meaning it takes one rainy image as input and directly outputs its rain-free counterpart, without requiring temporal information from surrounding video frames.

The network's first design choice is working in the YCrCb color space rather than RGB. Instead of processing all three color channels, it isolates the Y (luminance) channel, which carries most of the structural and textural detail where rain streaks are visually apparent, and leaves the Cr/Cb (chrominance) channels untouched. These color channels are simply carried through and reattached to the output at the end. This keeps color fidelity intact while letting the network dedicate its full capacity to reconstructing fine structural detail, rather than spending parameters relearning color information that was never corrupted.

At its core, the architecture stacks 20 Residual Channel Attention Blocks (RCABs). Each RCAB combines a standard two-layer convolutional residual block with a channel attention mechanism (squeeze-and-excite style: global average pooling followed by a small bottleneck of 1×1 convolutions and a sigmoid gate), allowing the network to adaptively reweight which feature channels matter most for a given input, rather than treating all channels equally.

Rather than directly predicting the clean image, the network uses residual learning: it predicts the rain pattern itself as a residual, which is then subtracted from the original input and clamped to a valid pixel range. This is generally an easier optimization target than reconstructing an entire image from scratch, since the network only needs to model the (typically sparse) rain component.

Training is guided by a custom Structural Loss, combining a Charbonnier loss (a smooth, outlier-robust variant of L1) with a cosine-similarity-based structural term that helps protect perceptual/structural quality (reflected in SSIM), not just raw pixel accuracy. The model is optimized using AdamW with cosine annealing over 160 epochs, with gradient clipping to prevent instability. Performance is evaluated using PSNR, SSIM, and LPIPS, and the project includes a systematic ablation study isolating the contribution of each architectural and training choice — attention, residual learning, depth, width, loss design, and input representation.
